# Changelog

NovaDial is a fork of Fossify Phone.

For changes prior to the fork, see the Fossify Phone project history.

## [28] - 1.3.1

### Improved
- Enhanced data synchronization and cache updates
- Metadata and readme documentation updates

### Fixed
- Fixed screen flickering in the recent calls log
- Fixed ringer issue where sound played in vibrate mode

## [27] - 1.3.0

### Changed
- Suppressed Fossify donation prompts and badges

### Improved
- Improved call duration display formatting
- Updated default contact avatar generation
- Enhanced theme and UI styling consistency

### Fixed
- Fixed incoming call screen dismissal delay
- Resolved call history display lag upon call termination

## [26] - 1.2.0

### Added
- Added QR code contact sharing option
- Support custom ringtones for individual contacts
- Added maximum ringtone volume override feature

### Improved
- Redesigned call details and history layout

## [25] - 1.1.0

### Added
- Added persistent in-call notifications
- Added quick Speaker toggle directly from the notification
- Added quick Mute toggle directly from the notification

### Changed
- Active call notifications can no longer be accidentally dismissed
- Outgoing answered calls now remain clearly identified

## [24] - 1.0.2

### Performance
- Performance optimizations and bug fixes

### Fixed
- Fixed default dialer permission handling
- Fixed issues affecting dialer usability on some devices

## [23] - 1.0.1

### Changed
- Updated application icon and brand logo
- Removed legacy setups and popups

### Improved
- UI refinements and stability improvements

## [22] - 1.0.0 - Initial NovaDial Release

Initial NovaDial release.

### Added
- Forked from Fossify Phone

### Improved
- Optimized Recents performance
- Faster contact loading in Recents
- Better contact matching
- Enhanced UI responsiveness
